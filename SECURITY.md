# Security Policy

## Scope

This repository contains research-only code and synthetic examples. It should never contain live credentials, broker configuration, private datasets, runtime state or production deployment material.

## Reporting

If you discover a credential, private endpoint, sensitive operational detail, or other accidental disclosure in the public repository, please report it privately to the repository owner rather than opening a public issue containing the sensitive value.

## Non-goals

This project is not a live trading service and does not accept or route real orders. Production security controls for the private system are outside this repository.
